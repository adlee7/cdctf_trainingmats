What is Reverse Engineering & Pwn?

Reverse engineering (RE) is the process of figuring out what a program does without having its source code — by reading its logic, whether that's a readable script or a compiled binary, and working out what transformations it applies to its input.

Binary exploitation (pwn) goes a step further: instead of just understanding a program, you find a flaw in how it handles memory or input and use that flaw to make it do something it wasn't supposed to — anything from leaking data to hijacking its execution entirely.

These two skills are usually grouped together because they share the same starting point: reading and understanding a program's logic. A reversing challenge often ends once you understand the code well enough to compute an answer; a pwn challenge usually begins right there, using that understanding to craft an exploit.

Common Challenge Types

  • Script / Bytecode Reversing: Working out the logic of a program written in a scripting or interpreted language, often readable with little more than careful reading and some scratch-paper math.
  • Static Binary Analysis: Disassembling or decompiling a compiled binary to read its logic without ever running it.
  • Dynamic Analysis: Running a binary under a debugger to observe its behavior, inspect memory, and test hypotheses about what it's doing.
  • Memory Corruption (Pwn): Exploiting bugs like buffer overflows to overwrite memory and redirect a program's execution.
  • Exploit Scripting: Automating the delivery of a crafted exploit against a remote service, typically with a library like pwntools.

Toolbox

Reverse Engineering Tools

  • Ghidra: A free, NSA-developed software reverse engineering suite with a powerful decompiler, widely used as the default choice for CTF binary analysis.
  • IDA Free: A free edition of the industry-standard disassembler/decompiler, IDA Pro.
  • dogbolt.org: A free online service that runs an uploaded binary through several different decompilers at once and lets you compare their output side by side — no local install required.
  • Cutter (built on radare2): A free, open-source reverse engineering platform with a graphical interface.

Pwn Tools

  • GDB: The standard command-line debugger on Linux, essential for dynamic analysis and exploit development.
  • pwntools: A Python library purpose-built for writing and automating exploits against CTF-style binaries and remote services.
  • checksec: Quickly reports which binary protections (stack canaries, ASLR, NX, PIE) are enabled on a target — useful for scoping out a pwn challenge before you dive in.
