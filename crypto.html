What is Cryptography?

Cryptography is the practice of protecting information by transforming it so that only someone with the right knowledge (a key, an algorithm, or both) can recover the original content. In a CTF, cryptography challenges hand you some transformed data — ciphertext — and ask you to work backward to recover the plaintext flag.

A key distinction worth internalizing early: encoding is not encryption. Formats like Base64 and hexadecimal just represent the same bytes differently and require no secret key to reverse — they make binary data safe to print or transmit as text. Encryption, by contrast, is specifically designed to be irreversible without a key or some weakness in the algorithm. Many CTF crypto challenges layer both: data is encrypted, then encoded, so you have to peel back the encoding before the real cryptanalysis even starts.

Classical Ciphers

Classical ciphers predate computers and operate directly on letters, which makes them a common starting point for beginner-friendly challenges. Spotting what stays the same between ciphertext and plaintext — letters only, preserved spacing, preserved punctuation — is often your best first clue that you're looking at one of these.

CipherHow It Works
Caesar / ROTShifts every letter by a fixed number of positions in the alphabet (ROT13 shifts by 13).
AtbashReverses the alphabet: A↔Z, B↔Y, and so on — a fixed substitution with no key.
VigenèreShifts each letter by an amount determined by a repeating keyword, making it a polyalphabetic cipher.
AffineApplies a mathematical function ((ax + b) mod 26) to each letter's numeric position.

All of these preserve capitalization, whitespace, and punctuation, and only ever substitute one letter for another — which is exactly the kind of pattern you should be looking for when you suspect a classical cipher is in play.

Modern Cryptography

Modern cryptography operates on raw bytes rather than letters, and is generally split into two families:

  • Symmetric encryption (e.g. AES, XOR ciphers): The same key is used to encrypt and decrypt. XOR is especially common in CTFs because it's simple, fast, and — critically — its own inverse: XOR-ing ciphertext with the same key recovers the plaintext.
  • Asymmetric encryption (e.g. RSA): Uses a mathematically related key pair — a public key to encrypt, a private key to decrypt. CTF challenges in this space often exploit weak key generation or small parameters rather than breaking the underlying math directly.

Cribbing: A Core Technique

When you suspect data has been encrypted with a simple, reversible operation, a crib — a guess at a piece of known plaintext (like cdctf{, since you know every flag starts with it) — lets you test that guess against the start of the ciphertext. If applying an operation (XOR, subtraction, etc.) between your crib and the ciphertext produces a clean, repeating pattern, you've likely found both the operation and the key.

Toolbox

  • CyberChef: A browser-based "data manipulation" tool with building blocks for encoding/decoding, classical ciphers, XOR, and much more — chain operations together into a reusable recipe.
  • dCode: A large collection of online cipher solvers and identifiers, including an automatic cipher identifier if you're not sure what you're looking at.
  • quipqiup: An automatic solver for substitution ciphers that works from letter-frequency analysis alone.
  • OpenSSL: A command-line toolkit for working with modern cryptographic primitives (hashing, symmetric/asymmetric encryption, certificates).
  • RsaCtfTool: Automates common RSA attacks against weak keys, a staple for CTF-style RSA challenges.
