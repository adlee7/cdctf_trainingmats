What is Digital Forensics?

Digital forensics is the practice of identifying, extracting, and analyzing data from digital artifacts — disk images, memory dumps, individual files, filesystems, and more — in order to answer a question or reconstruct what happened. In a CTF, that usually means working through one or more artifacts to recover a hidden flag.

Unlike OSINT, which focuses on publicly available information, forensics challenges hand you a file or image directly and ask you to dig into its structure: What format is it? What's hidden inside it? What does its metadata or filesystem reveal? Each of those questions usually points you toward a different tool.

Common Forensics Challenge Types

  • File Identification & Carving: Figuring out what type of file or archive you're dealing with, then extracting or decompressing it correctly.
  • Disk & Filesystem Analysis: Mounting or browsing a disk image to recover files, partitions, or deleted data.
  • Steganography: Finding data hidden inside another file — often an image or audio file — using techniques like LSB encoding or dedicated embedding tools.
  • Metadata Analysis: Examining the hidden fields attached to a file (EXIF data, document properties) for clues or hidden content.
  • File Carving & Embedded Files: Detecting and extracting one file that's been hidden inside another, often by appending it after the first file's end-of-data marker.
  • Memory & Filesystem Forensics: Using filesystem-specific features (journals, snapshots) or memory images to recover data that isn't visible through normal browsing.

Toolbox

These are the core tools you'll lean on throughout this MAT. You don't need to memorize every flag or option — just know roughly what each tool is for, and come back to its documentation when you need specifics.

Compression & Archives

  • file: Identifies a file's type by inspecting its contents (magic bytes) rather than trusting its extension.
  • unzip: Extracts files from a ZIP archive.
  • gunzip: Decompresses GZIP-compressed files.
  • bunzip2: Decompresses BZIP2-compressed files.
  • unxz: Decompresses XZ-compressed files.

Disk & Memory Analysis

  • Autopsy: A graphical digital forensics platform for browsing disk images, recovering files, and viewing filesystem artifacts.
  • Volatility: A command-line framework for analyzing memory image dumps.
  • The Sleuth Kit: A suite of command-line tools for analyzing disk images and filesystems.
  • losetup: A Linux utility that lets you mount a raw image file as a usable block device.
  • btrfs-progs: Command-line tools for working with the Btrfs filesystem, including its snapshot and journal features.

Metadata & Steganography

  • ExifTool: Reads and edits metadata embedded in image and document files.
  • zsteg: Detects hidden data in PNG and BMP files, commonly used for LSB steganography.
  • steghide: Embeds and extracts hidden data in image and audio files using a passphrase.
  • Aperi'Solve: An online platform that runs an image through several steganography and metadata tools at once.

File Carving & General Analysis

  • CyberChef: A browser-based "data manipulation" tool with building blocks for decoding, extracting, and transforming data, including an Extract Files block.
  • binwalk: Scans a file for embedded files and executable code, and can extract what it finds.
  • strings: Prints printable character sequences found in a binary file, often useful for spotting readable clues.
  • dd: Copies and converts raw data, often used to extract a specific byte range from a larger file.
  • A hex editor (e.g. HxD or GHex): Lets you view and edit the raw bytes of a file, essential for fixing corrupted headers or checksums.

A Note Before You Start

Not every tool above will be used in every challenge. Part of the forensics skillset is narrowing down which tool fits the artifact in front of you — the file command is almost always a good first move when you're not sure what you're looking at.

Part 1: Decompression, Identification, and Partitions

This part starts at the very beginning: you're handed a compressed artifact and need to figure out how to decompress it, identify what kind of artifact it actually is, choose an appropriate analysis tool, and then make sense of its partitions and filesystems before you can look for anything inside.

Tools You'll Use

  • unxz/gunzip/bunzip2/unzip — to decompress the artifact
  • Autopsy, Volatility, The Sleuth Kit, or losetup — to analyze the resulting artifact, depending on its type

Part 3: Carrier Files and Embedded Archives

Sometimes one file simply has another file appended to the end of it. This part covers spotting a file that's larger than it should be, detecting an embedded file inside it, and extracting and decompressing what you find.

Tools You'll Use

  • binwalk — to scan for and extract embedded files
  • CyberChef's Extract Files block — as an alternative way to pull embedded files out of a larger one
  • unxz (or another decompression tool matching the archive type you find) — to decompress whatever was embedded
