# Training Mats Challenges for CDCTF!

## About Crimson Defense CTF (CDCTF)

Crimson Defense Cyber Security Club's virtual 12-hour Jeopardy-style Capture-the-Flag competition is designed for collegiate-level players. All ability levels are welcome. CDCTF will not only provide satisfying challenges for seasoned players, but be a good introduction to CTFs for new ones!

[Check out the official CDCTF website](https://crimsondefense.org/cdctf/)

## About the Training Mats

Training Mat challenges were designed to be a brief but helpful introduction to CTF topics for newcomers! One aspect of CTFs that makes it harder for newcomers to get into CTFs is the technical skills that are needed to excel in such competitions. These Mats are designed to bridge the gap. The purpose of these challenges is to introduce useful tools and a brief overview of skills needed for different CTF categories. Some are designed to be skipped for those who are experienced in CTFs and do not need the Training Mat introduction.
